# Entrechat — site informativo

Página pública e política de privacidade da versão local do Entrechat. Hospedagem estática prevista no GitHub Pages. Este repositório contém apenas páginas informativas; não inclui configuração OAuth, autorizações de contas ou dados de chat.

Arquivos: index.html, privacy.html e style.css. Sem instalação de dependências ou etapa de build.
